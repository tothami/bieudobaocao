Ứng dụng tạo biểu đồ thanh từ dữ liệu file excel hoặc CSV do người dùng tải lên.
File dữ liệu nên có tối thiểu 3 cột:
- một cột để làm bộ lọc (như lọc theo thời gian). Người dùng có thể lọc theo một hoặc nhiều giá trị trong cột này
- một cột để gán giá trị vào trục hoành (X) (như loại sản phẩm)
- một cột để gán giá trị vào trục tung (Y). Thường thì cột này nên có giá trị số (như doanh thu)

-----------------------------------------------------------------------------------------------

Khi chưa có file dữ liệu tải lên, ứng dụng sẽ trình bày một bộ dữ liệu mẫu để người dùng tham khảo.
